# 🧭 Career Compass
An AI-driven technical assessment and personalized career readiness platform developed as a Capstone Project for **FY MCA (2026–2028), MES's Institute of Management & Career Courses (IMCC), Pune**.
---
## 📌 About the Project
**Career Compass** evaluates students' technical readiness for industry jobs through:
- **MCQ & Coding Assessments** (with integrated Monaco Editor & local code execution sandbox).
- **Anti-Cheat Proctoring** (Fullscreen enforcement, strike counter, and violation snapshots).
- **Weakness Detection** (Identifies weak, average, and strong technical topics).
- **AI-Powered Learning Roadmaps** (Synthesizes custom study plans via local Ollama LLM).
- **Job Readiness Scoring** (Tracks progress and gates reassessment until practice tasks are complete).
---
## 🛠️ Tech Stack
- **Frontend:** React 18, Vite, Tailwind CSS, Monaco Editor
- **Backend:** Spring Boot 3, Java 17+, Spring Security (JWT)
- **Database:** PostgreSQL 15+
- **Code Execution Sandbox:** Piston (Docker)
- **Local AI Engine:** Ollama (`llama3.2:3b`)
